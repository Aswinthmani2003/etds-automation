================================================================================
  ETDS PDF Renamer — Batch Processing Guide (250+ Files)
================================================================================

LOCAL PROCESSING IS FASTEST! 🚀

For processing large batches (250+ files), local is 3-5× faster than cloud.

================================================================================
  QUICK START
================================================================================

1. Double-click: Start ETDS Dashboard.bat
   → Dashboard opens at http://localhost:5000

2. Upload files:
   • Excel report: Your ETDS Excel file
   • Scanned PDFs: Select ALL 250+ PDFs (drag & drop all at once)

3. Click: "Process & Rename"
   → Progress bar shows: 1 / 250, 2 / 250, etc.

4. Wait for completion
   → Typical: 10-20 minutes for 250 files

5. Download ZIP
   → All renamed PDFs ready to use

================================================================================

Files  | Time       | Speed

================================================================================
  HOW IT WORKS (Behind the Scenes)
================================================================================

Fast Hybrid Mode:
┌─ Fast Scan (150 DPI, 2 pages)
│  └→ Found 95% of barcodes in 1-2 sec each
│     ✓ Return immediately
│
└─ Tough PDFs (5%)
   └→ Auto-retry with Thorough Scan (300/200/150 DPI, all pages)
      └→ Catches edge cases
      └→ Takes 3-5 sec extra, but gets them all

Result: Speed for most files, accuracy for all.

================================================================================
  TIPS FOR 250+ FILES
================================================================================

✓ Best: Process at night or idle time (won't slow your computer for work)
✓ Organize PDFs in one folder for easy selecting
✓ Use drag & drop to select all (faster than clicking)
✓ Don't close browser/bat window while processing
✓ Safe to leave unattended - won't stop until done

⚠ Avoid: Processing while using heavy software
⚠ Avoid: Unplugging power during processing

================================================================================
  IF IT GETS STUCK
================================================================================

Problem: Progress bar frozen on same PDF

Solution:
1. Wait 2-3 minutes (thorough scan is slower)
2. If still stuck after 5 min:
   → Close bat window (Ctrl+C)
   → Close browser
   → Try again with smaller batch (50 files)

If problem persists:
→ One PDF might be corrupted
→ Try removing suspicious PDFs and retry

================================================================================
  TROUBLESHOOTING
================================================================================

Q: Why is it slow?
A: Barcode detection is CPU-intensive. 250 files @ ~5-10 sec each = 20-40 min.
   Faster CPUs = faster processing.

Q: Can I speed it up more?
A: No. Current hybrid mode balances speed + accuracy perfectly.
   Any faster = miss some barcodes.

Q: What if Excel and PDFs don't match?
A: App shows results:
   • OK → Barcode found and matched Excel
   • no_barcode → PDF has no readable barcode
   • not_found → Barcode not in Excel file
   • error → PDF processing failed

   Download report to see which ones had issues.
